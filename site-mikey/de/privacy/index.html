Datenschutz

Stand 2026-10-30. Kurz: MiKey sammelt nichts.

Die Eingabe

  • Alles passiert auf deinem Gerät. MiKey schickt nicht, was du tippst.
  • Auf dem Mac stellt die MiKey-Eingabequelle keine Netzwerkverbindung her.
  • Unter Windows prüft MiKey einmal täglich auf Updates, indem es mikey.mikephung.com/appcast.xml lädt. Diese Anfrage ist wie jeder Website-Aufruf (IP-Adresse, Browser-Typ) und enthält nichts über dich oder dein Getipptes. In den Einstellungen abschaltbar.
  • Unter Windows gibt es ein "Tipp-Protokoll" zur Fehlersuche. Es ist ausgeschaltet, bleibt auf deinem Gerät und zeichnet nie in Passwortfeldern auf.

Diese Website

  • Die Website besteht aus statischen HTML-Dateien: keine Cookies, keine Statistik, keine Werbung, keine externen Schriften oder Skripte.
  • Ausgeliefert wird sie über Cloudflare. Wie jeder Webserver verarbeitet Cloudflare deine IP-Adresse, um die Seite zu senden und Angriffe abzuwehren.
  • Die Download-Knöpfe führen zu GitHub, mit eigener Datenschutzerklärung.

Kontakt

  • Fragen zum Datenschutz: ein Issue auf GitHub eröffnen oder über mikephung.com.

MiKey basiert auf Vikey von Tony Dinh und OpenKey von Tuyen Mai.
