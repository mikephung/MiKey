Voraussetzungen

  • macOS 13 Ventura oder neuer, Mac mit Apple Silicon oder Intel.
  • Windows 10 oder 11, x64 oder ARM64.
  • Jedes Tastaturlayout: Schweiz, deutsch · Deutsch · ABC/US · Österreich.

Installation auf dem Mac

  1. MiKey-1.0.3-macOS.dmg laden, öffnen und Cài đặt MiKey.pkg doppelklicken. Dieselbe Datei für Macs mit Apple Silicon (M1–M4) und Intel.
  2. macOS meldet, dass Apple die Software nicht auf Malware prüfen konnte: Fertig klicken. Das liegt daran, dass das Paket nicht mit einem Apple-Zertifikat signiert ist.
  3. Systemeinstellungen › Datenschutz & Sicherheit öffnen, nach unten scrollen, bei MiKey Trotzdem öffnen klicken und das Passwort eingeben.
  4. Fortfahren, Installieren. Das Installationsprogramm kopiert MiKey nach ~/Library/Input Methods (dein Benutzerordner) und schaltet es ein.
  5. Bei der ersten Installation: einmal ab- und wieder anmelden ( › Abmelden). macOS nimmt eine neue Eingabequelle erst nach dem nächsten Anmelden ins Eingabemenü auf. Bei Updates ist das nicht nötig.
  6. MiKey im Eingabemenü in der Menüleiste wählen. Darunter bleibt dein Layout aktiv, zum Beispiel Schweiz, deutsch.

Update: neue Version laden und darüber installieren. Entfernen: MiKey aus den Eingabequellen nehmen und ~/Library/Input Methods/MiKey.app löschen (Finder › Gehe zu › Gehe zum Ordner).

Installation unter Windows

  1. MiKey-1.0.3-x64-Setup.exe laden (oder arm64 für ARM-Geräte).
  2. Windows SmartScreen meldet Der Computer wurde durch Windows geschützt: Weitere Informationen › Trotzdem ausführen. Grund wie auf dem Mac: nicht signiert.
  3. MiKey wird nur für dein Benutzerkonto installiert, ohne Administratorrechte.
  4. MiKey sitzt im Infobereich (unten rechts). Alt+Z schaltet Vietnamesisch ↔ Englisch/Deutsch.

Update: MiKey sucht einmal täglich nach neuen Versionen und installiert nur von MiKey signierte. Entfernen: Einstellungen › Apps › MiKey › Deinstallieren.

Datei prüfen

Die SHA-256-Prüfsumme oben muss zu deiner Datei passen. Mac: shasum -a 256 MiKey-*.pkg. Windows (PowerShell): Get-FileHash MiKey-*.exe.

MiKey basiert auf Vikey von Tony Dinh und OpenKey von Tuyen Mai.
