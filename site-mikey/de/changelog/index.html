MiKey 1.0.3

2026-10-30 · GitHub

Nach der Installation sofort tippen, ohne Abmelden.

  • macOS: MiKey wird in deinen Benutzerordner installiert (~/Library/Input Methods), wie Version 1.0.0. Im gemeinsamen Ordner /Library übernimmt macOS eine neue Eingabequelle erst nach dem nächsten Anmelden, darum fehlte 1.0.1 und 1.0.2 manchmal im Eingabemenü.
  • Update von 1.0.1/1.0.2: Die alte Kopie in /Library wird entfernt, damit es nur ein MiKey gibt. Erscheint MiKey nicht sofort, einmal ab- und wieder anmelden.
  • Die letzte Seite des Installationsprogramms sagt, wie es weitergeht, auf Vietnamesisch, Deutsch und Englisch.

MiKey 1.0.2

2026-10-30 · GitHub

Behebt das Update.

  • Eine Installation über eine ältere Version lässt MiKey nicht mehr aus dem Eingabemenü verschwinden: Das Installationsprogramm wartet, bis macOS mit der alten Kopie fertig ist, registriert MiKey danach und prüft, bis es stabil gelistet bleibt.
  • War MiKey die aktive Eingabequelle, bleibt es das auch nach dem Update.
  • Schon auf 1.0.1 aktualisiert und MiKey ist weg? 1.0.2 darüber installieren, dann ist es wieder da.

MiKey 1.0.1

2026-10-30 · GitHub

Behebt die Installation auf einem neuen Mac.

  • macOS: Nach der Installation erscheint MiKey sofort im Eingabemenü (auf einem neuen Mac war es zuvor nur als App sichtbar, erst nach dem Abmelden als Eingabequelle).
  • Das Installationsprogramm installiert immer nach /Library/Input Methods und räumt eine ältere MiKey-Kopie im Benutzerordner weg.
  • Logo und Links in der Menüleisten-App: MiKey statt Vikey.

MiKey 1.0.3

2026-10-30 · GitHub

Erste Version von MiKey.

  • macOS: MiKey ist eine echte Eingabequelle im Eingabemenü (InputMethodKit), ohne Bedienungshilfen-Berechtigung.
  • ä ö ü ß é und die Tottasten (´ ^ ¨) auf deutschen und Schweizer Tastaturen werden nicht mehr von Telex zu ơ oder ư gemacht.
  • Erkennt rund 30'000 deutsche Wörter (wir, der, dass…), zusätzlich zu Englisch.
  • Tech-Wörter wie osx, macos, exe bekommen keine Akzente mehr.
  • Behoben: Nach Löschen oder Klicken klebte das neue Wort am vorherigen (đawng, tootho).
  • Windows: dieselben Korrekturen für deutsche/Schweizer Tastaturen, eigenes Installationsprogramm, signierte Updates.

MiKey basiert auf Vikey von Tony Dinh und OpenKey von Tuyen Mai.
