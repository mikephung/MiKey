Yêu cầu

  • macOS 13 Ventura trở lên, Mac Apple Silicon hoặc Intel.
  • Windows 10 hoặc 11, x64 hoặc ARM64.
  • Bất kỳ layout bàn phím nào: Schweiz, deutsch · Deutsch · ABC/US · Österreich.

Cài trên macOS

  1. Tải MiKey-1.0.3-macOS.dmg, mở nó, rồi bấm đúp Cài đặt MiKey.pkg. Cùng một file cho Mac Apple Silicon (M1–M4) và Mac Intel.
  2. macOS báo không thể mở vì Apple không thể kiểm tra phần mềm độc hại: bấm Xong. Đây là vì bản cài chưa được ký bằng chứng chỉ Apple.
  3. Mở System Settings › Privacy & Security, kéo xuống, bấm Open Anyway cạnh dòng MiKey, rồi nhập mật khẩu máy.
  4. Bấm Continue, Install. Bộ cài chép MiKey vào ~/Library/Input Methods (thư mục của bạn) và tự bật nó.
  5. MiKey có ngay trong menu bàn phím. Chưa thấy? Mở System Settings › Keyboard › Input Sources › Edit…, bấm +, chọn Vietnamese › MiKey › Add. Vẫn chưa có thì đăng xuất rồi đăng nhập lại một lần.
  6. Chọn MiKey trong menu bàn phím ở thanh menu (cạnh đồng hồ). Bàn phím bên dưới vẫn là layout bạn đã chọn, ví dụ Schweiz, deutsch.

Cập nhật: tải bản mới và cài đè lên. Gỡ: bỏ MiKey khỏi Input Sources, rồi xoá ~/Library/Input Methods/MiKey.app (Finder › Go › Go to Folder).

Cài trên Windows

Bộ cài Windows đang được hoàn thiện và sẽ có trên trang phát hành trong vài ngày tới.

  1. Tải MiKey-1.0.3-x64-Setup.exe (hoặc bản arm64 cho máy ARM).
  2. Windows SmartScreen báo Windows protected your PC: bấm More info › Run anyway. Lý do giống trên Mac: bản cài chưa được ký.
  3. MiKey được cài cho riêng tài khoản của bạn, không cần quyền quản trị.
  4. MiKey nằm ở khay hệ thống (góc dưới bên phải). Alt+Z để chuyển Việt ↔ Anh/Đức.

Cập nhật: MiKey tự kiểm tra bản mới mỗi ngày và chỉ cài bản có chữ ký của MiKey. Gỡ: Settings › Apps › MiKey › Uninstall.

Kiểm tra file

Mã SHA-256 ở bảng trên phải khớp với file bạn tải về. Trên Mac: shasum -a 256 MiKey-*.pkg. Trên Windows (PowerShell): Get-FileHash MiKey-*.exe.
