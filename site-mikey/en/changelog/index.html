Changelog

Newest version first.

MiKey 1.0.3

2026-10-30 · GitHub

Type right after installing, no log out needed.

  • macOS: MiKey is installed in your user folder (~/Library/Input Methods), as in 1.0.0. In the shared /Library folder macOS only takes a new input method after the next log in, so 1.0.1 and 1.0.2 could be missing from the input menu.
  • Upgrading from 1.0.1/1.0.2: the old copy in /Library is removed so there is one MiKey only. If MiKey doesn't show up at once, log out and back in once.
  • The installer's last page says what to do next, in Vietnamese, German and English.

MiKey 1.0.2

2026-10-30 · GitHub

Fixes upgrading.

  • Installing over an older version no longer makes MiKey vanish from the input menu: the installer waits until macOS is done with the old copy, then registers MiKey and checks until it stays listed.
  • If MiKey was the active input source, it still is after the upgrade.
  • Already on 1.0.1 and lost MiKey? Install 1.0.2 over it and it is back.

MiKey 1.0.1

2026-10-30 · GitHub

Fixes installing on a new Mac.

  • macOS: after installing, MiKey shows up in the input menu right away (on a new Mac it used to appear only as an app, and as an input source only after logging out).
  • The installer always installs into /Library/Input Methods and removes an older MiKey copy in the user folder.
  • Logo and links in the menu bar app: MiKey instead of Vikey.

MiKey 1.0.3

2026-10-30 · GitHub

First MiKey release.

  • macOS: MiKey is a real input source in the input menu (InputMethodKit), no Accessibility permission needed.
  • ä ö ü ß é and the dead keys (´ ^ ¨) on German and Swiss keyboards are no longer turned into ơ or ư by Telex.
  • Recognises about 30,000 German words (wir, der, dass…) as well as English.
  • Tech words such as osx, macos, exe no longer get tone marks.
  • Fixed: after deleting or clicking, the next word was glued to the previous one (đawng, tootho).
  • Windows: the same German/Swiss keyboard fixes, its own installer, signed updates.

MiKey is based on Vikey by Tony Dinh and OpenKey by Tuyen Mai.
