Type Vietnamese, German and English. Without switching keyboards.

MiKey is a Vietnamese Telex input method for people living in Switzerland, Germany and Austria. It notices English and German words by itself, and the ä ö ü keys just work.

No more silly Telex mistakes

Telex turns the letters s f r x j w into tone marks. Great for Vietnamese, bad for every other word. MiKey knows about 70,000 English and German words and leaves them alone.

ä ö ü just work

On Swiss and German keyboards ü sits where Telex expects the [ key, so it became ơ. MiKey leaves ä ö ü ß é alone: über, Grüße, Café, Zürich.

Knows German

wir, der, nur, dass, wissen don't turn into ửi, dẻ, nủ, das, ưisen. Can be turned off in the menu.

Knows English and tech words

text, server, the best test, osx, macos, exe stay as typed. Common Vietnamese words like gì and ít always stay Vietnamese.

Switch with ⌥Z / Alt+Z

One key for Vietnamese ↔ English/German, with a small VI/EN label at the cursor.

Wrong guess? Backspace

If MiKey gets a word wrong, Backspace right after it brings back what you typed.

Everything stays on your computer

Nothing is sent anywhere. On the Mac, MiKey is a real input source and needs no Accessibility permission.

Install

macOS

  1. Download MiKey-…-macOS.pkg from the releases page and open it.
  2. The first time, macOS asks because the package isn't signed by Apple yet: right-click the file › Open, or System Settings › Privacy & Security › Open Anyway.
  3. System Settings › Keyboard › Input Sources › Edit… › + › Vietnamese › MiKey.
  4. Pick MiKey in the input menu in the menu bar. Done.

Windows

  1. Download MiKey-…-x64-Setup.exe (or arm64) from the releases page.
  2. Windows SmartScreen may warn because the installer isn't signed yet: More info › Run anyway.
  3. MiKey lives in the system tray. Alt+Z switches Vietnamese ↔ English/German.

FAQ

Is MiKey free?

Yes. MiKey is free and open source (GPL-3.0). The code is on GitHub.

Does MiKey send what I type anywhere?

No. Everything happens on your computer. No ads, no analytics, no account.

Does it need the Accessibility permission on the Mac?

No. MiKey is a macOS input source, like ABC or Swiss German.

What if a word is guessed wrong?

Press Backspace right after it to get back exactly what you typed. If you don't need German detection, turn off "Nhận biết tiếng Đức" in the input menu.

Does it work with a Swiss or German (QWERTZ) keyboard?

Yes, that's what it's made for. It reads the characters of the layout you use, so z/y and ä ö ü are right.

How is it different from Vikey and OpenKey?

MiKey is based on Vikey (Tony Dinh), which is based on OpenKey (Tuyen Mai). MiKey adds what Vietnamese people in German-speaking countries need: umlaut keys, German words, tech words.
