Privacy

Updated 2026-10-30. In short: MiKey collects nothing.

The input method

  • Everything happens on your computer. MiKey does not send what you type anywhere.
  • On the Mac, the MiKey input method makes no network connections.
  • On Windows, MiKey checks for updates once a day by downloading mikey.mikephung.com/appcast.xml. This request is like any page visit (IP address, browser type) and contains nothing about you or what you type. It can be turned off in the settings.
  • On Windows there is a "typing log" for debugging. It is off by default, stays on your computer and never records in password fields.

This website

  • The website is static HTML files: no cookies, no analytics, no ads, no external fonts or scripts.
  • It is served through Cloudflare. Like any web server, Cloudflare processes your IP address to deliver the page and block attacks.
  • The download buttons lead to GitHub, which has its own privacy policy.

Contact

  • Privacy questions: open an issue on GitHub or get in touch through mikephung.com.

MiKey is based on Vikey by Tony Dinh and OpenKey by Tuyen Mai.
